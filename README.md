# 🚀 Hybrid Chat System (NestJS)

A real-time AI + Human Agent hybrid chat backend built with **NestJS**, **MongoDB**, and **Swagger API documentation**.

---

## 📦 Features

* AI + Human Agent Chat System
* Conversation Management
* Real-time Messaging (WebSocket ready)
* Round Robin Agent Assignment
* MongoDB with Mongoose
* Swagger API Documentation

---

## 🛠️ Tech Stack

* **Backend:** NestJS
* **Database:** MongoDB (Mongoose)
* **API Docs:** Swagger
* **Language:** TypeScript

---

## 📥 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/eodaneze/Hybrid-AI-Agent-Chat-Backend.git
cd Hybrid-AI-Agent-Chat-Backend
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Setup Environment Variables

Create a `.env` file in the root directory:

```env
check the .example.env
```

---

### 4. Start the Application

#### Development Mode

```bash
npm run start:dev
```

#### Production Mode

```bash
npm run build
npm run start:prod
```

---

## 🌐 Running the App

Once the server starts, your app will be available at:

```
http://localhost:${PORT}
```

---

## 📚 Swagger API Documentation

Swagger is enabled for testing all endpoints.

Open in your browser:

```
http://localhost:${PORT}/docs
```
